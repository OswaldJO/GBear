## Updates
- **Sleep, TV volume and stuck covers release (Oct 2 2026):** Release **v1.4.1** ships the three entries below (BJ-130). Only the Mac app is new; the companion apk and Windows guest are the same as v1.4.0. **Action:** install **GBear-macOS.zip** from v1.4.1; allow Local Network access when GBear looks for a Roku.
- **Covers that never downloaded now show (Oct 2 2026):** A scrape that found a cover but couldn't download it used to save the web address as the cover, so the game looked covered, nothing showed, and later scrapes skipped it. RomM-synced games also brought ScreenScraper addresses tied to RomM's login, which never load. GBear now uses its own ScreenScraper login for those addresses, doesn't count a failed download as a cover (the scrape log says why it failed), and at launch and after each scrape downloads every cover still saved as a web address (BJ-130). Scrape logs in Downloads no longer include your ScreenScraper passwords. **Action:** open the new build once; the GBA / GB / GBC covers (and any other stuck ones) fill in.
- **Controller volume goes to the TV (Oct 2 2026):** While the Mac's sound plays through a TV over HDMI, **Select + L1 / R1** change the TV's volume instead of the Mac's, through a USB-CEC adapter (Pulse-Eight with `brew install libcec`, any TV) or a Roku TV over Wi‑Fi; the adapter is used when both are there. New **Streaming → TV** section: on / off, Roku picker, **Find Again**, and which way it's going. With neither, or on other speakers, volume stays on the Mac. Brightness stays on the Mac (TVs take no brightness commands). TV off / on with the Mac's sleep / wake is the Mac's own HDMI-CEC (M4 MacBook Pro and other recent Macs), nothing GBear sends. macOS asks for Local Network access the first time GBear looks for a Roku.
- **Sleep the Mac with Start + R2 (Oct 2 2026):** Holding **Start + R2** for 5 seconds puts the Mac to sleep, in GBear or in a game; no Accessibility permission needed.
